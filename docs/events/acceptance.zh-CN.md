# Super-Org 验证记录

使用 [2048 人工验收清单](../2048-manual-acceptance.zh-CN.md) 开展真实项目验证。每项证据应注明使用的是自动测试、隔离模型环境还是真实平台。

| 验证层次 | 已核对范围 |
| --- | --- |
| 自动测试 | 有序事件、事务回滚、配置隔离、重启恢复、原工单跟进、交付版本、阻塞通知、Issue 同步及 PR/行讨论回写。仓库和消息发送使用测试替身 |
| 真实模型隔离 | Codex 根据语言和上下文区分 PR 答疑与修改，选择回复或跟进原工单。外部发送、执行和项目状态均使用隔离环境 |
| 真实群与项目 | 真钉钉入站经队列调用 Agent，登记一次检查预约。计时器到期唤起 Agent，无变化则静默。首次答复确认使用 Markdown 并有平台发送回执。原 B 工单的阻塞通知和后续输入均有实际记录 |
| 真实仓库 | 已读取关联 Issue 的远端状态。真实 PR 评论、行评审、Review 到执行结果回写仍待端到端验收 |
